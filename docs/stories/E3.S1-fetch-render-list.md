# Story E3.S1 — Fetch and render the todo list

**Epic:** E3 — Frontend Todo Experience
**Status:** Ready for Dev
**Estimate:** M
**Traces to:** PRD FR3, FR9, FR10; Architecture §7

## User story
> As a user, I want to see my todos when I open the app, so that I know what's on my plate.

## Acceptance criteria
1. On mount, the app calls `GET /api/todos` via the `useTodos()` hook and renders the result.
2. While the initial fetch is pending, a skeleton (or spinner) is shown.
3. When the list is empty (after loading completes), an `EmptyState` component displays a hint to add the first todo.
4. When the fetch fails, an error toast appears with a `Retry` button that re-runs the query.
5. Each `TodoItem` renders the title, completion checkbox, and delete affordance (interactions wired in subsequent stories).

## Technical notes
- React Query: `useQuery(["todos"], api.list, { staleTime: Infinity })`.
- `staleTime: Infinity` because mutations explicitly invalidate `["todos"]` — we don't need background refetches.

## Test strategy

### Unit tests
- **U1.** `<EmptyState />` renders the expected hint and a focusable "Add a todo" affordance.
- **U2.** `<Skeleton />` renders 3 skeleton rows with appropriate `aria-busy="true"`.

### Integration tests (RTL + MSW)
- **I1.** Loading state: mock the API to delay; assert the skeleton renders, then the list replaces it.
- **I2.** Empty state: mock the API to return `[]`; assert `EmptyState` renders.
- **I3.** Populated list: mock 3 todos; assert each item renders by accessible name.
- **I4.** Error state: mock a 500; assert the toast appears with `Retry`; clicking Retry triggers another fetch (assert MSW saw 2 requests).

### E2E tests (Playwright)
- **E1.** Cold open: navigate to `/`; assert either `EmptyState` or list is visible within 3 s; no `console.error`.

### Verification commands
```
npm test --workspace=frontend -- TodoList
npx playwright test e2e/tests/happy-path.spec.ts
```

## Definition of Done
- ACs met; loading / empty / populated / error states all verified by tests.
