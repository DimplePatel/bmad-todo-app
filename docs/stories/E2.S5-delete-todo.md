# Story E2.S5 — `DELETE /api/todos/:id`

**Epic:** E2 — Backend CRUD API & Persistence
**Status:** Ready for Dev
**Estimate:** S
**Traces to:** PRD FR6, FR13; Architecture §6

## User story
> As a user, I want to delete a todo, so that I can remove it from my list.

## Acceptance criteria
1. Returns `204 No Content` on success.
2. Returns `404` if `:id` does not exist.
3. Returns `400` if `:id` is not a UUID.
4. Subsequent `GET /api/todos` does not include the deleted row.

## Technical notes
- Repository's `delete` returns `boolean`; `false` → `404`.

## Test strategy

### Unit tests
- **U1.** `todos.service.delete.test.ts` — passes through to `repo.delete(id)`.

### Integration tests
- **I1.** Happy path: create then delete → second `GET /api/todos` does not include it.
- **I2.** Unknown id → `404`.
- **I3.** Non-UUID id → `400`.

### E2E tests (Playwright)
- _Covered via E3.S4 undo flow and E4.S5 happy path._

### Verification commands
```
npm test --workspace=backend -- todos.delete
curl -X DELETE http://localhost:3001/api/todos/<id> -i
```

## Definition of Done
- ACs met; 204/400/404 all covered.
