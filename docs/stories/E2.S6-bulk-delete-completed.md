# Story E2.S6 — Bulk delete completed

**Epic:** E2 — Backend CRUD API & Persistence
**Status:** Ready for Dev
**Estimate:** S
**Traces to:** PRD FR8; Architecture §6

## User story
> As a user, I want to clear all completed todos in one action, so that I can tidy my list quickly.

## Acceptance criteria
1. `DELETE /api/todos?completed=true` removes all rows with `completed = 1` and returns `200` with `{ "deleted": <count> }`.
2. With no completed rows, returns `{ "deleted": 0 }`.
3. Active rows are untouched.
4. Returns `400` if the `completed` query parameter is missing or not `true` (we reserve other values for future scoping).

## Technical notes
- Single SQL statement: `DELETE FROM todos WHERE completed = 1` — `better-sqlite3` exposes `info.changes` which becomes `deleted`.
