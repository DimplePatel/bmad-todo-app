# Story E3.S2 — Add a todo (optimistic)

**Epic:** E3 — Frontend Todo Experience
**Status:** Ready for Dev
**Estimate:** M
**Traces to:** PRD FR1, FR2, FR11, NFR1; Architecture §7.4

## User story
> As a user, I want to type a task and press Enter to add it, so that capture is instant.

## Acceptance criteria
1. The `TodoInput` accepts 1–200 characters; submitting empty/whitespace shows an inline error and does not call the API.
2. On submit, the UI optimistically prepends the new todo at the top of the list with a temporary client `id`.
3. On API success (`201`), the optimistic entry is replaced with the server's response (real `id`, timestamps).
4. On API failure, the optimistic entry is removed and an error toast with `Retry` appears.
5. The input is cleared on successful submit; on failure the typed text is preserved so the user can retry.

## Technical notes
- React Query mutation with `onMutate` (snapshot + optimistic prepend), `onError` (rollback), `onSuccess` (replace temp id with server entry by deep-merging into `["todos"]`).
- Form uses native `<form onSubmit>` so Enter submits naturally.

## Test strategy

### Unit tests
- **U1.** Inline validation: typing 201 characters disables submit; empty submit shows the inline error.

### Integration tests (RTL + MSW)
- **I1.** Happy path: type "buy milk" + Enter → optimistic row appears at top → server resolves → row's `id` updates to server uuid; input cleared.
- **I2.** Failure rollback: MSW returns 500 → optimistic row disappears, toast with Retry shown, input retains text.
- **I3.** Whitespace-only submit: API is **not** called; inline error visible.
- **I4.** Click Retry on the toast → mutation re-runs against MSW.

### E2E tests (Playwright)
- **E1.** `e2e/tests/happy-path.spec.ts` step: type a title, press Enter, assert the new row is present and the input is empty.

### Verification commands
```
npm test --workspace=frontend -- TodoInput
npx playwright test e2e/tests/happy-path.spec.ts
```

## Definition of Done
- ACs met; rollback path verified; toast retry verified.
