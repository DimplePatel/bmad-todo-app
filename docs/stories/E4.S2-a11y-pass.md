# Story E4.S2 — Keyboard & accessibility pass

**Epic:** E4 — Polish, A11y & Deploy Readiness
**Status:** Ready for Dev
**Estimate:** S
**Traces to:** PRD NFR4

## User story
> As a user who relies on keyboard or assistive tech, I want the app to be navigable and clear, so that I can manage my tasks without barriers.

## Acceptance criteria
1. All interactive elements are reachable via Tab in a logical order matching visual order.
2. Visible focus rings are present on every focusable element.
3. Icon-only buttons (delete, clear completed) have descriptive `aria-label`s including the todo's title where relevant.
4. List uses `<ul>`/`<li>` semantics; checkboxes are real `<input type="checkbox">`.
5. Color contrast meets WCAG 2.1 AA on all text and interactive elements (verified by an automated checker).
6. Filter chips expose `aria-pressed`.
7. Toast container has `role="status"` (polite live region); error toasts use `role="alert"` for assertive notification.

## Technical notes
- Add an automated a11y check using `axe-playwright` to flag obvious violations.

## Test strategy

### Unit tests
- **U1.** Each component asserts `aria-*` attributes on its focusable elements.

### Integration tests (RTL)
- **I1.** Tab order test renders `<App />` with two todos, simulates `Tab` keypresses, and asserts focus order: input → filter chips → first item checkbox → first item delete → second item checkbox → second item delete → clear completed (when present).

### E2E tests (Playwright + axe)
- **E1.** `e2e/tests/a11y.spec.ts`:
  - Navigate to `/` with seed data.
  - Run `await injectAxe(page); await checkA11y(page, null, { detailedReport: true });`.
  - Expect zero serious or critical violations.
- **E2.** Keyboard-only flow: Tab to input, type "kb test", Enter; Tab to checkbox, Space to toggle; Tab to delete, Enter — all without using the mouse.

### Verification commands
```
npm test --workspace=frontend -- a11y
npx playwright test e2e/tests/a11y.spec.ts
```

## Definition of Done
- ACs met; axe scan reports 0 serious/critical issues; keyboard-only flow passes.
