# Story E1.S3 — React frontend skeleton

**Epic:** E1 — Project Foundation & Health
**Status:** Ready for Dev
**Estimate:** S
**Traces to:** Architecture §3, §7

## User story
> As a developer, I want a Vite-based React app in TypeScript, so that I have a place to build the Todo UI.

## Acceptance criteria
1. `frontend/` boots with `npm run dev --workspace=frontend` on `:5173`.
2. The app renders a placeholder `<h1>Todo App</h1>`.
3. `vite.config.ts` proxies `/api` → `http://localhost:3001` for local dev.
4. React Query and the Zod-shared types from `packages/shared` are installed and importable (no usage required yet).
5. `npm test --workspace=frontend` passes a smoke test that renders `<App />` and asserts the heading.

## Technical notes
- Use `@vitejs/plugin-react` and React 18+ with `createRoot`.
- Configure `vite-tsconfig-paths` so `@shared/*` resolves from `packages/shared/src`.
- Strict mode wrapper around the app root.

## Test strategy

### Unit tests
- **U1.** `App.test.tsx` (RTL): renders `<App />` and asserts `screen.getByRole("heading", { name: /todo app/i })` is in the document.
- **U2.** Vite proxy config sanity check: import `vite.config.ts` defaults and assert `server.proxy['/api'].target === 'http://localhost:3001'`.

### Integration tests
- _None at this layer; covered in later stories with React Query + MSW._

### E2E tests
- _Deferred to E1.S4 / E4.S5._

### Verification commands
```
npm run dev --workspace=frontend
npm test --workspace=frontend
```

## Definition of Done
- App boots, heading renders, proxy works (visible by hitting `/api/health` from the dev server), tests green.
