# Story E3.S4 — Delete with undo

**Epic:** E3 — Frontend Todo Experience
**Status:** Ready for Dev
**Estimate:** M
**Traces to:** PRD FR6, FR11; Architecture §7.4

## User story
> As a user, I want to delete a todo and have a brief undo window, so that mistakes are recoverable.

## Acceptance criteria
1. Clicking delete optimistically removes the row from the list.
2. A toast appears for 5 s with an `Undo` button.
3. If `Undo` is pressed before the timer elapses, the pending DELETE is **cancelled** (never sent to the server) and the row reappears.
4. If the timer elapses, the DELETE is sent to the server. On success, the row stays removed. On failure, the row is restored and an error toast with Retry appears.
5. Deleting multiple todos in quick succession queues independent toasts; each undo is scoped to its own todo.

## Technical notes
- Implement deferred dispatch in a small `useDeferredDelete` hook: it manages the `setTimeout`, the cancel handle, and the toast lifecycle.
- The toast host stacks toasts and dismisses them after 5 s on hover-out.

## Test strategy

### Unit tests
- **U1.** `useDeferredDelete` cancels its timer when `undo()` is called.

### Integration tests (RTL + MSW + fake timers)
- **I1.** Click delete → row hidden; advance timers 5 s → MSW saw `DELETE`.
- **I2.** Click delete → click Undo within 5 s → MSW saw 0 `DELETE` requests; row visible.
- **I3.** Click delete → MSW returns 500 after 5 s → row reappears, error toast with Retry shown.
- **I4.** Two deletes in quick succession queue two toasts; undoing only the second restores only that row.

### E2E tests (Playwright)
- **E1.** `e2e/tests/undo-delete.spec.ts`:
  - Create a todo, delete it, click Undo within the toast → assert row is back.
  - Create another, delete, wait 6 s → reload page → assert row is gone (server actually deleted it).

### Verification commands
```
npm test --workspace=frontend -- delete
npx playwright test e2e/tests/undo-delete.spec.ts
```

## Definition of Done
- ACs met; undo and elapsed paths covered; failure rollback covered.
