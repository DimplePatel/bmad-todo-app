# Story E1.S4 — Dockerfiles + docker-compose

**Epic:** E1 — Project Foundation & Health
**Status:** Ready for Dev
**Estimate:** M
**Traces to:** PRD NFR7 (portability), NFR2 (durability), Architecture §9

## User story
> As a developer, I want one-command local startup, so that anyone can run the app from a clean checkout without Node tooling.

## Acceptance criteria
1. Multi-stage `backend/Dockerfile` produces a slim production image (`node:20-alpine` base; `npm ci --omit=dev` final stage).
2. Multi-stage `frontend/Dockerfile` builds the Vite app and serves the static output via `nginx:alpine` with a custom `nginx.conf` that proxies `/api/*` to `http://backend:3001`.
3. `docker-compose.yml` defines `backend`, `frontend`, and a named volume `todo-db` mounted at `/data` inside `backend`.
4. `docker-compose.override.yml` provides dev-only port mappings (`5173:80`, `3001:3001`) and bind-mounts source for hot reload during dev.
5. `docker compose up --build` from a clean checkout produces a working app within 60 s on a typical broadband machine; `http://localhost:5173/api/health` returns `200`.
6. `docker compose down` followed by `docker compose up` preserves any data written to the SQLite file (the volume is `todo-db`, not anonymous).

## Technical notes
- Use a `.dockerignore` per workspace so `node_modules`, `dist`, and tests are not copied into images.
- Backend `CMD` is `node dist/index.js`; frontend final stage runs `nginx -g 'daemon off;'`.
- Healthcheck on the backend container (`HEALTHCHECK CMD curl -f http://localhost:3001/api/health`) so the frontend can `depends_on: { backend: { condition: service_healthy } }`.

## Test strategy

### Unit tests
- **U1.** Lint `Dockerfile`s with `hadolint` (CI step).

### Integration tests
- **I1.** `compose-up.test.ts` (CI script): boots the stack with `docker compose up -d --wait`, polls `http://localhost:5173/api/health` until `200`, then asserts elapsed time < 60 s. Tear down with `docker compose down -v`.

### E2E tests (Playwright)
- **E1.** `e2e/tests/smoke.spec.ts` is upgraded:
  - **Given** the Compose stack is up,
  - **When** Playwright navigates to `/`,
  - **Then** the `<h1>Todo App</h1>` is visible and `GET /api/health` returns `200`.

### Verification commands
```
docker compose up --build
curl http://localhost:5173/api/health
docker compose down                # data preserved
docker compose up                  # bring back; data still present
```

- All ACs met; the CI compose-up integration test is green; the named volume is documented in the README.
