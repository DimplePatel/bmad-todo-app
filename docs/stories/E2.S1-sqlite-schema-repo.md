# Story E2.S1 — SQLite schema + repository

**Epic:** E2 — Backend CRUD API & Persistence
**Status:** Ready for Dev
**Estimate:** M
**Traces to:** PRD NFR2, NFR8, NFR9; Architecture §4.5, §5

## User story
> As a developer, I want a typed repository with a versioned schema, so that data access is consistent, parameterized, and easy to evolve when auth is added.

## Acceptance criteria
1. `DATABASE_PATH` env var is honored (default `./data/todos.db` in dev, `/data/todos.db` in container).
2. A migration runner reads `db/migrations/*.sql` in lexicographic order and applies any not yet recorded in `schema_migrations`.
3. `001_init.sql` creates the `todos` table per Architecture §5.1 and an index on `created_at DESC`.
4. `SqliteTodoRepository` implements the `TodoRepository` interface from Architecture §4.5 with parameterized queries.
5. Repository methods generate `id` (UUID v4), `createdAt`, `updatedAt` as ISO 8601 strings.
6. Mapping between the DB row (with `0/1` for `completed`) and the domain `Todo` (with `boolean`) is centralized in one helper.
7. ESLint rule (or grep check in CI) blocks string-concatenated SQL in `repositories/`.

## Technical notes
- Use `better-sqlite3` (synchronous; matches the simple, non-async repository signature).
- Pragmas on connection: `PRAGMA journal_mode = WAL;` and `PRAGMA foreign_keys = ON;`.
- Each test creates a temp DB file in `tmp/` and disposes it afterwards; never use shared state.

## Test strategy

### Unit tests
- **U1.** `migrate.test.ts` — running migrations on a fresh file produces the `todos` table and the index; running a second time is a no-op (idempotent).
- **U2.** `repository.list.test.ts` — empty DB returns `[]`; with three seeded rows, returns them ordered by `createdAt` desc.
- **U3.** `repository.create.test.ts` — generates a UUID v4 `id`, sets timestamps, `completed=false`.
- **U4.** `repository.update.test.ts` — updates `title` and/or `completed`; refreshes `updatedAt`; returns `null` on missing id.
- **U5.** `repository.delete.test.ts` — returns `true` on hit, `false` on miss.
- **U6.** `repository.deleteCompleted.test.ts` — deletes only completed rows; returns the count; leaves active rows untouched.
- **U7.** `mapping.test.ts` — round-trips `Todo` ↔ row.
